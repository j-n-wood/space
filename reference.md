# Reference notes

Bits and pieces of original behaviour to consider retaining or not.

## System clearance events

Clearing a system tends to unlock some event.

1. SCG construction
2. hyperlight capability
3. PTL - or resource cache

order less certain:

4. Pirate captain
5. Prison pod (resolves prior)
6. Blazer (orbital defence laser)
7. Sonic blaster (easter egg)
8. Game completion
